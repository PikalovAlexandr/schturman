# Штурман: Система управления жизненным циклом изделий (PLM)

Современная PLM-система, написанная на Rust с интеграцией ИИ-агентов.

## Описание

Штурман — это кросс-платформенная система управления жизненным циклом изделий (Product Lifecycle Management), аналог ЛОЦМАН:PLM, созданная с использованием современных технологий и архитектурных подходов.

## Ключевые возможности

- **Управление компонентами**: создание, версионирование, отслеживание статусов
- **Управление документами**: загрузка CAD-файлов, PDF, версионирование, checkout/checkin
- **Спецификации (BOM)**: иерархические структуры, сравнение версий, where-used запросы
- **Управление изменениями**: ECO/ECR, workflow согласований, отслеживание влияния
- **Интеграция ИИ**: семантический поиск, анализ CAD, валидация BOM, генерация документации

## Технологический стек

### Backend
- **Язык**: Rust
- **Веб-фреймворк**: Axum + tonic (gRPC)
- **Базы данных**:
  - PostgreSQL + TimescaleDB (основное хранилище)
  - SurrealDB (графовые связи, BOM)
  - Qdrant (векторный поиск для ИИ)
- **Очереди**: NATS
- **Хранилище файлов**: MinIO (S3-совместимое)
- **Поиск**: Meilisearch

### Frontend
- **Desktop**: Tauri (Rust + SvelteKit/React)
- **Кросс-платформенность**: Linux, Windows, macOS

### ИИ-интеграция
- Локальные модели: candle/burn (Rust)
- Векторные эмбеддинги: qdrant-client
- Оркестрация: langchain-rust / llm-chain
- Внешние API: OpenAI, Anthropic, локальные LLM

## Архитектура

Микросервисная архитектура с выделенными сервисами:

```
services/
├── auth-service/          # Аутентификация и авторизация
├── part-service/          # Управление компонентами
├── document-service/      # Управление документами
├── bom-service/          # Спецификации (BOM)
├── change-service/       # Управление изменениями
└── ai-orchestrator/      # Оркестратор ИИ-агентов

ai-agents/
├── semantic-search/      # Семантический поиск
├── cad-parser/          # Анализ CAD-файлов
└── llm-tasks/           # LLM-задачи
```

## Быстрый старт

### Требования

- Rust 1.75+ (MSRV)
- Docker и Docker Compose
- PostgreSQL 15+
- Node.js 18+ (для frontend)

### Запуск инфраструктуры

```bash
# Запуск баз данных и сервисов
docker compose up -d

# Применение миграций
cargo install sqlx-cli
sqlx migrate run

# Запуск сервисов
cargo run --bin part-service
cargo run --bin document-service
# ... остальные сервисы

# Запуск frontend
cd frontend
npm install
npm run tauri dev
```

## Разработка

### Структура workspace

Проект организован как Rust workspace с несколькими crates:

- `services/*` - микросервисы
- `ai-agents/*` - ИИ-агенты
- `shared/*` - общие библиотеки
- `frontend/` - desktop-приложение

### Команды разработки

```bash
# Проверка кода
cargo clippy --all-targets --all-features

# Форматирование
cargo fmt --all

# Тесты
cargo test --workspace

# Сборка
cargo build --release
```

## Производительность

Целевые метрики:

- CRUD операций с компонентами: <50ms (p95)
- BOM-запросы (1000 элементов): <200ms
- Семантический поиск: <100ms
- Загрузка документов (100MB): <5s
- Поддержка одновременных пользователей: 100+ (горизонтальное масштабирование)

## Безопасность

- JWT-аутентификация с коротким временем жизни токенов
- RBAC (Role-Based Access Control)
- Шифрование файлов в хранилище
- Аудит всех изменений
- Rate limiting на API
- Валидация входных данных
